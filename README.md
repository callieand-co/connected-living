# Connected Living — curated by DISC

A gallery-style index of objects, tools, studios and voices for an intentional digital life,
with looks you try on in the Fitting Room.

**DISC = Digital Independence Supply Co.**

Prototype v1. Static HTML/CSS/JS, no build step. All content lives in `data/*.json`.

- `/` home · `/directory.html` the index · `/object.html#i=<slug>` product · `/setup.html#s=<slug>` fitting room
- `/design-system/` the design system

Placeholder product imagery throughout; press thumbnails in `img/media/` belong to their publishers.
